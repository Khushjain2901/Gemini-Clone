# Gemini Clone 🤖

A modern, responsive AI chatbot inspired by Google Gemini, built using **React, Vite, JavaScript, and the Google Gemini API**.

## 📸 App Preview

![Gemini Clone App Preview](./src/assets/app_preview.png)

## ✨ Features

- 🤖 AI-powered conversations using Google Gemini
- 💬 Interactive chat interface
- ⚡ Fast React + Vite frontend
- 🎨 Gemini-inspired UI
- 📱 Responsive design
- 🔄 Real-time AI responses
- 🧭 Sidebar navigation
- ⌨️ Simple and intuitive prompt input

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- Google Gemini API
- CSS
- npm
